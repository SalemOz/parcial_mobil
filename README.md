
Aplicación móvil/web hecha con Ionic 9 + Angular 22.

## Requisitos previos

- Node.js 20 o superior
- npm

## Instalación

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm start
```

Abre `http://localhost:4200` en el navegador.

## Otros comandos

```bash
npm run build        # compilar para producción
```
